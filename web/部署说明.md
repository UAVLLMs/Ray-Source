# 网页端部署

## 环境
- Node.js 18 或更高版本
- 已运行的召回服务，例如 `http://127.0.0.1:8014`

## 配置
1. 复制 `.env.example` 为 `.env`。
2. 设置 `RAGV6_API_ORIGIN` 和 `RAGV6_CHAT_ORIGIN` 为召回端地址。
3. `RAGV6_API_TOKEN` 必须与召回端 `KAFU_API_TOKEN` 完全一致。
4. 生产环境建议启用 Redis；单实例可保持 `RAGV6_REDIS_REQUIRED=0`。

## 启动
```powershell
npm ci
./start.ps1
```

默认访问地址为 `http://127.0.0.1:3011`。通过 `WEB_HOST=0.0.0.0` 暴露到局域网或反向代理；公网必须配置 HTTPS。

## 验收
```powershell
Invoke-WebRequest http://127.0.0.1:3011/health
```
浏览器打开首页并发送“你好”，应收到客服短答。再发送一条产品问题，右侧应实时出现检索审计。
