# 召回端部署

## 环境
- Python 3.11 或 3.12
- 建议 8 GB+ 内存；图片向量检索首次加载会占用额外内存
- 可选 Redis 7，用于跨实例检索缓存

## 配置
1. 创建虚拟环境并安装依赖：
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
2. 复制 `.env.example` 为 `.env`。
3. 必填项：`KAFU_API_TOKEN`、生成模型 Provider、Embedding Provider；若启用 Rerank，填写 Rerank Provider。
4. 网页端的 `RAGV6_API_TOKEN` 必须等于本端 `KAFU_API_TOKEN`。

## 启动
```powershell
./start.ps1 -ListenHost 0.0.0.0 -Port 8014 -Python .\.venv\Scripts\python.exe
```

数据目录 `data/` 已包含知识块、FAISS/图片向量索引、图片 caption 与手册图片。不要删除 `data/index`、`data/manual-images` 或各 `.npz` 索引文件。

## 验收
```powershell
Invoke-WebRequest http://127.0.0.1:8014/health
```
应返回 `status: ok`。再由网页网关发送一条问题，确认返回 SSE `audit` 与 `done` 事件。
